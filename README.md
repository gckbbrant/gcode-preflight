# CNC G-code Preflight

[![CI](https://github.com/gckbbrant/gcode-preflight/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/gckbbrant/gcode-preflight/actions/workflows/ci.yml)

A MoonBit command-line preflight checker for a deliberately limited three-axis
milling G-code dialect. It checks travel limits and estimates program time.
